# Epic Battle Game

A Java project designed to master object-oriented programming concepts through the development of an interactive strategy game.

## Overview

**Epic Battle Game** is a turn-based strategy simulation where two rival factions—the **Nobility** and the **Commoners**—engage in tactical combat until one faction is completely eliminated. The game features dynamic unit interactions, random battle outcomes, and strategic gameplay mechanics.

## Game Modes

### Console Version
The original implementation runs entirely in the console, providing a text-based tactical experience with detailed battle logs and real-time combat information.

### Graphics Version (libGDX)
An extended version leveraging the libGDX framework brings the battles to life with:
- Pixel art graphics reminiscent of late 90s computer games
- Dynamic sound effects and audio feedback
- Visual unit animations and battle sequences
- Enhanced user interface for better gameplay experience

## Features

- **Two Opposing Factions**: Nobility vs Commoners with unique characteristics
- **Random Battle Mechanics**: Unpredictable outcomes make each battle unique
- **Turn-Based Combat**: Strategic decision-making and tactical gameplay
- **Cross-Platform Support**: Available in both console and graphical implementations

## Technologies

- **Language**: Java
- **Graphics Framework**: libGDX (optional)
- **Architecture**: Object-Oriented Design Patterns

## Purpose

This project serves as an educational platform to practice and demonstrate:
- Object-oriented programming principles
- Event-driven programming
- Multi-platform development
